## Fixed In Repository

| Finding | Change |
| --- | --- |
| Cloudflare HTTP-200 error bodies produced false DNS success | Both Octelium DNS reconcilers now reject transport, malformed, missing-success, and `success:false` responses; a mocked regression covers both helpers without exposing tokens |
| Future release jobs inherited broad read permission | Workflow default is now deny-all; each current job retains its explicit least-privilege scope |
| Redundant GitHub concurrency syntax required an Actionlint suppression | Removed default `queue: single`, its stale exact assertion, and the one-off linter suppression |
| Control-plane onboarding applied Talos config before validation | Added strict metal validation immediately before the maintenance-mode apply |
| 35 Terragrunt-owned Applications declared normalized-away empty Kustomize options | Removed the no-op objects and reject their return in the static gate |
| Six retired Deluge split-profile secrets remained readable | Kept them as state tombstones but removed External Secrets reader IAM access |
| One explicit Terragrunt unit had no provider lock | Added the Kubernetes provider lock and require a lock for every explicit unit |
| Grafana and OctoBot mounted unused Kubernetes API credentials | Disabled service-account token automount and added Helm-values assertions |
| Media backup depended on a historical ordinal PVC | GitOps now declares the matching retained `data-media-postgres-0` claim with pruning and Application-deletion disabled |
| OpenClaw liveness killed recoverable work repeatedly | Kept fast readiness but extended liveness to a six-minute bound pending rollout and observation |
| OpenClaw Codex hook relays escaped timeout ownership | Pin all OpenClaw containers to stable `2026.8.2`, which contains the upstream Linux relay PID-ownership fix, while retaining the protective `4Gi` memory limit |
| OpenClaw restart bootstrap failed on transient npm resets | Reuse an already verified exact Discord plugin and bound first-install retries instead of force-downloading it on every Pod start |
