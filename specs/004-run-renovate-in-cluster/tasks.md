2. Stage US1 with the CronJob suspended, verify Secret projection, retire transfer grants, then unsuspend into full dry-run mode through reviewed GitOps. Complete US2 cache persistence and freshness proof before writes.
3. Complete US3 in a window after the last legacy daily run: pass dry-run parity, delete the legacy workflow, verify every scheduled/manual run has left nonterminal states, retire the repository Actions private key with the guarded post-delete receipt, then enable cluster writes through GitOps. Keep the cluster dry-run until deletion, drainage, and key retirement complete. On rollback, stop and drain cluster write Jobs, then repair or revert the cluster runner; accept a no-writer gap before the first proven cluster writer. Restore the legacy key and workflow only after GitHub-hosted Harbor reachability and the guarded fallback gates pass. Validate the seven-day outcomes after cutover.
4. Finish the cross-cutting gates and retain the read-only evidence and rollback commands in the operator docs.
