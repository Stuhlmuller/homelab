# Homelab Wiki Contract

Maintain a focused repository wiki for agents adding features and fixing bugs.
Start at quickstart.md and follow task routes; preserve existing operational
notes and historical evidence. Update only affected pages and route new pages
from quickstart or a relevant overview.

Use current repository code as the source of desired state. Distinguish dated
findings, proposed changes, local validation, merged source, deployed state,
and live acceptance. Never convert an unverified runtime claim into a fact.
Keep canonical source paths visible and verify important statements before
registering Claims. Preserve unresolved recovery and security gates.

Use standard relative Markdown links and descriptive OKF metadata. Keep public
secret references only. Honor .openwikiignore, repository AGENTS.md safety
boundaries, and existing authorization. Wiki work never authorizes production
mutations. Use update, not init, to preserve migrated pages.
