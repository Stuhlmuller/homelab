# NOFX

NOFX runs the `ghcr.io/nofxaios/nofx` backend and frontend images as a private
tailnet application at `https://nofx.stinkyboi.com`.

The backend stores its SQLite database and logs on the `nofx-data` NFS PVC at
`/app/data`. Runtime secrets are sourced from AWS SSM through External Secrets:

- `/homelab/nofx/jwt-secret` is generated by the SSM parameter stack.
- `/homelab/nofx/data-encryption-key` is generated by the SSM parameter stack.
- `/homelab/nofx/rsa-private-key` must be replaced with a PEM RSA private key.
- `/homelab/nofx/claw402-wallet-key` must be replaced with a funded CLAW402
  wallet key before paid AI calls can work.

Rollout depends on External Secrets, Istio ambient, Octelium tailnet ingress,
and the `nfs-default` storage class.
